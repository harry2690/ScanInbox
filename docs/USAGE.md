# 操作、網路與資料管理

ScanInbox 的產品定位是 Mac 掃描接收器；目前僅支援 SHARP 事務機掃描接收，其他品牌尚未納入支援範圍。

## 視窗與背景接收

開啟管理視窗或共用設定時會顯示 Dock 圖示，可用 Command+Tab 切回。縮小視窗不隱藏 Dock。關閉最後一個 App 視窗才切回選單列常駐，背景接收持續運作；從選單列可重新開啟。結束 App 才會停止接收。

## 自動偵測多張網卡

App 每五秒更新啟用中的 IPv4 介面，排除 loopback 與 169.254 自動配置位址，也可能列出 VPN 或虛擬網路。偵測到位址不代表印表機一定可達，請選擇印表機可以連通的 Mac 位址設定目的地。

服務同時監聽 IPv4 網路介面；只有印表機清單中已啟用的來源 IP 可登入。不支援 IPv6 接收。Mac IP 改變時須更新印表機目的地，程式不會遠端改寫通訊錄。

## FTP 資料連線

- 控制埠預設 TCP 4687，可在共用設定調整。
- 被動模式資料埠固定為 Mac TCP 50000–50009。
- 主動模式由 Mac 連回印表機所指定的資料埠，該埠可能每次不同。

網路或防火牆必須允許實際使用模式的連線方向；不能只根據「匿名登入成功」判定文件可傳送。

## 登入後啟動

將 App 放在固定位置，再到共用設定勾選「登入 Mac 後啟動」並儲存。必要時在系統「登入項目」允許。若要登入後直接接收，也勾選「程式啟動時開始接收」。

程式優先使用 SMAppService；若本機建置無法使用該服務，則依使用者選擇建立專用使用者 LaunchAgent。取消勾選會移除註冊。搬動 App 後請重新關閉、開啟該選項以更新路徑。登入啟動、重新登入與休眠恢復應在實際環境各自驗證。

## 檔案與紀錄

| 資料 | 位置 |
|---|---|
| 印表機與共用設定 | ~/Library/Application Support/SharpScanner/settings.json |
| 掃描紀錄 | 同目錄 history.sqlite3 及 SQLite WAL 檔 |
| 診斷日誌 | 同目錄 Logs/receiver.log |
| 掃描文件 | 每台印表機自行設定的輸出資料夾 |
| 備援登入排程 | ~/Library/LaunchAgents/tw.local.SharpScanner.login.plist |

紀錄保留期間只清除紀錄，不刪掃描文件；畫面最多顯示最新 5,000 筆。檔案搬走後，舊紀錄仍可能存在，但 Finder 定位會提示檔案不存在。

## 排查接收問題

| 現象 | 檢查方向 |
|---|---|
| 無法開始接收 | 是否已新增並啟用印表機、Python 是否安裝、埠是否被其他服務占用 |
| 完全沒有連入 | 影印機目的地、Mac 位址、休眠與網路可達性 |
| 來源遭拒 | 設定的 IP 是否等於實際印表機來源 |
| 登入成功但上傳失敗 | 主動／被動資料連線、區域網路權限與網路過濾規則 |
| 同名檔案遭拒 | 改用新的檔名；App 不會覆寫已有文件 |
| 子目錄不存在 | 在接收資料夾預先建立，或將處理目錄改為空白／根目錄 |

需要進一步排查時，在共用設定開啟診斷記錄後重試。記錄可能含 IP、檔名及路徑，公開前必須移除個人資訊。App 不記錄 FTP 密碼參數。

## 使用限制

目前採匿名明文 FTP，僅適合可信任的區網；不提供 FTPS、帳密驗證、檔案配額、防毒或文件內容驗證。來源 IP 限制不等於身分驗證，不應對網際網路公開。

接收目錄不可讓其他程序同時修改目錄結構。App 拒絕下載、覆寫、刪除既有檔案、追加與續傳；明確中止時嘗試移除殘檔，斷電或強制結束可能留下檔案。正常 FTP 傳輸完成也不代表 PDF 內容已驗證，仍須開啟確認。
